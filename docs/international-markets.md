# Топ-20 країн для продукту (2026-10-24)

Відтворення: `python -I scripts/rank-countries.py` → `docs/data/country-ranking.json`. Ваги й оцінки — у скрипті, їх можна змінити.

## Що це за рейтинг
Це **експертна оцінка за 6 критеріями, а не вимірювання**. Різниця менш ніж у 3–4 бали — шум, і порядок усередині груп умовний.

| Критерій | Вага |
|---|---|
| Економіка без субсидій (ціна електрики/тепла/утилізації) | 25 % |
| Сировина (тваринництво, харчова переробка) | 20 % |
| Ринковий імпульс (діючі гранти/тарифи/мандати для малих проєктів) | 20 % |
| Доступність для нас (мова, відстань, ризик) | 15 % |
| Видимий попит (Trends, кількість станцій) | 10 % |
| Прогалина (мало безкоштовних незалежних розрахунків) | 10 % |

Позначки доказів: **V** — підтверджено в цій роботі, **T** — виміряно в Google Trends (лише UA, PL, CZ, DE, TR, HU, US, CA), **K** — моя загальна обізнаність, **не перевірена**, це гіпотеза.

## Чого немає (обмеження)
- Google Trends виміряно лише для 8 країн. Повторна спроба для 32 країн упиралася в `TooManyRequestsError` (Google обмежує частоту); дані загубилися. Для повного порівняння треба запускати `scripts/trends3.py` порціями з паузами або через Keyword Planner.
- Для більшості країн (позначка K) у цьому дослідженні не перевірено ні ціни електрики, ні тарифи, ні кількість станцій.
- Індія та Бразилія стоять високо через масштаб і політику, але з низькою доступністю для нас; в іншому профілі ваг вони впадуть.
- Перевірені джерела: IEA Outlook for Biogas and Biomethane; EBA/GIE 2025; CIBiogás 2025 (Бразилія); Renewable Watch, Deccan Herald (Індія); CIB та Il Sole 24 Ore (Італія); Usine Nouvelle, Chambres d'agriculture (Франція); Dentons, Schoenherr (Угорщина); Invest in Latvia.
