## 1. Назва

**Methalytics** = *methane* + *analytics*.

- Одразу каже, що це аналітика, а не продаж обладнання — головна позиція бренду.
- Однаково читається англійською, німецькою, польською, турецькою, португальською; локальні асоціації й вимову потрібно підтвердити носіями мов; незалежної перевірки всіх локалей немає.
- Коротка, вимовна, придатна для .com і для назви звіту («Methalytics Feasibility Report»).
- Ширше за «біогаз»: охоплює біометан/RNG/CBG — важливо для індустрії, девелоперів і муніципалітетів.

Дескриптор під логотипом (локалізується): *Biogas & biomethane feasibility*. Слоган: *Know if biogas pays — before you build.*

## 2. Позиціювання

Прозора попередня техніко-економічна оцінка біогазових і біометанових концепцій. Ми не продаємо установки або послугу експерта; базова оцінка за замовчуванням не покладається на субсидії (виняток legacy input — в economics.md). Межі процесної моделі й якість доказів мають бути зрозумілі клієнту; не обіцяти незалежну експертизу, охоплення всієї галузі чи підтверджену точність.

Аудиторії: ферми й агрохолдинги; харчова промисловість (бойні, молокозаводи, пивоварні, цукрово-спиртові та пальмоолійні заводи); девелопери та інвестори; муніципалітети й оператори відходів.

Кожне поле або селектор має допомагати розрахунку, рішенню клієнта чи наданню послуги. Дані лише для внутрішньої сегментації не повинні створювати додаткові запитання: використовуйте наявний контекст, а невідоме залишайте невідомим. Нові елементи форми додавайте лише за зрозумілої користі; додаткові параметри показуйте, коли вони потрібні для обраного сценарію.

## 3. Логотип

Молекула метану CH₄, у якій два передні зв'язки утворюють **галочку** (✓): вуглець — у вершині, водні — на кінцях, два інші водні — позаду (глибина). Ідея: «вердикт — у самій молекулі».

- SVG: `src/components/brand/Logo.tsx`, favicon `src/app/icon.svg`, OG-зображення `src/app/[lang]/opengraph-image.tsx`.
- Кольори: фон `#0b1d16`, сигнальний зелений `#3ddc97`, білий, бурштиновий акцент `#e8a521` (задній водень).
- Wordmark: `metha` + `lytics` (друга частина — сигнальним зеленим), шрифт Unbounded 600.

## 4. Анімована емблема (Three.js)

`src/components/three/MoleculeEmblem.ts` + `Emblem.tsx`:

- Тетраедрична модель CH₄ (фізично правильні кути 109,5°), PBR-матеріали з `RoomEnvironment` + PMREM — реалістичні відблиски без зовнішніх HDR.
- Спокійне обертання; кожні ~9 с молекула плавно (slerp) повертається в «позу галочки», де передні зв'язки підсвічуються — момент вердикту.
- Найкращі практики: `THREE.Timer`, рендер лише коли емблема у в'юпорті (`IntersectionObserver`) і вкладка активна, `devicePixelRatio` ≤ 2, коректний `dispose()` геометрій/матеріалів/рендерера, `prefers-reduced-motion` → статичний кадр, SVG-fallback без WebGL і до гідратації.
