# MVP scope

## Ціль
Знайти підприємства Західної України, де біогаз має позитивну економіку, і довести їх «від даних до рішення»: **analysis → feasibility → engineering decision → implementation path.** Не продавати обладнання на першому кроці.

## Що в MVP (зроблено в цьому репозиторії)

| # | Вимога | Реалізація |
|---|---|---|
| 1 | Homepage | `/` — меседж «Дізнайтесь, чи може ваш органічний відхід…», CTA «Розрахувати потенціал», анімована схема, чесний приклад, сегменти, принципи, FAQ |
| 2 | Анкета бізнес/сировина | `/calculator`: 9 простих питань у 4 кроки; без термінології; приклади-архетипи |
| 3 | Попередній калькулятор | `src/core` — feedstock-first, місячний теплобаланс, 3 схеми, діапазони, довіра, пропущені дані |
| 4 | Порівняння сценаріїв | Консервативний / Базовий / Оптимістичний, порівняння КГУ / котел / біометан, 8 стрес-тестів, беззбитковість |
| 5 | Простий звіт | блок результатів + деталі, друк у PDF, `/report/[id]` |
| 6 | Експертна консультація | форма «Замовити feasibility study» із прив'язкою розрахунку |
| 7 | CRM лідів | `/admin` (Basic Auth), статуси, нотатки, звіт по кожному ліду |

**Перший ринок:** Захід України (Львівська, Тернопільська, Івано-Франківська, Волинська, Закарпатська + Чернівецька, Рівненська, Хмельницька). Архітектура — міжнародна (CountryAdapter).

## Що НЕ в MVP (свідомо)
Операційна платформа (датчики, SCADA, предиктивне обслуговування), повноцінний GIS, серверний PDF, оплата, кабінет клієнта, інтеграція прайсів, кластерний режим, AI-розбір документів. Див. architecture.md §11.

## Гіпотези, які MVP має перевірити (метрики)

| Гіпотеза | Метрика | Поріг «підтверджено» |
|---|---|---|
| H1: переробники й середні тваринницькі підприємства мають достатній інтерес | конверсія калькулятор → заявка на ТЕО у цільових сегментах | ≥ 8 % завершених розрахунків |
| H2: чесний «ні» не знижує довіри | частка заявок серед тих, хто отримав WEAK/NOT; NPS після звіту | ≥ 15 % заявок від WEAK/«можливо за умов» |
| H3: калькулятор достатньо точний для скринінгу | розбіжність скринінг ↔ ТЕО по CAPEX і газу | ≤ ±30 % (CAPEX), ≤ ±25 % (біогаз) після BMP |
| H4: цільові сегменти перевершують гній | частка POSSIBLE/STRONG за сегментами | переробка > ферми |
| H5: клієнти готові платити за ТЕО | продажі ТЕО на 10 кваліфікованих лідів | ≥ 2 |

## План перших 90 днів (валідація, не код)
1. **Тижні 1–3:** 15 інтерв'ю (м'ясопереробка, молокозаводи, птахо-/свиноферми, пивоварні): рахунки, об'єми, вартість утилізації, готовність платити; заповнити C1–C2.
2. **Тижні 2–6:** 5–10 BMP у партнерській лабораторії; 3–5 запитів комерційних пропозицій (C4–C5); перекалібрувати каталог і CAPEX.
3. **Тижні 4–8:** повторний прогін 10 реальних клієнтів → порівняння з ручним ТЕО (H3).
4. **Тижні 6–12:** запуск лідгену по сегментах 1–2 (LinkedIn/профільні асоціації, галузеві виставки); 3 платних ТЕО.
5. **Паралельно:** юридичний огляд дозвільного шляху й дигестату (C6), підготовка PDF-шаблону ТЕО.

## Бізнес-модель
Безкоштовний калькулятор → платне ТЕО (діагностика, лабораторія, модель, концепція) → інжиніринг/проєктування → тендер постачальників → партнер-виконавець → пуск → моніторинг/сервіс. Низькі капітальні вимоги: платформа монетизує **відбір та експертизу**, а не обладнання.
